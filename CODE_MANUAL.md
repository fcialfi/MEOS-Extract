# Code Manual

This manual explains the source files of MEOS-Extract. Each section reproduces
the file with line numbers, followed by a block-level explanation of the
implementation, the data structures and the Python concepts involved.

> Generated by `scripts/build_code_manual.py` from the current sources: line
> numbers always match the listings. Re-run the script after changing the code.

## Overview

```
report HTML (MEOS)
   └─ Extract_all_charts.process_html()      one Excel per report: a sheet per chart
        ├─ lock statistics                   lock_state_stats.xlsx (GUI)
        ├─ polar / 3D plots                  PNG + interactive HTML, polar_plots_index.xlsx
        └─ report_analysis.run_analysis()    multi-orbit analysis → meos_processed.xlsx
gui_app.py                                   Tkinter front end driving all of the above
meos_extract.spec                            PyInstaller bundle (CLI + GUI executables)
```

How a chart becomes numbers: every chart in the report is an inline gnuplot
SVG. The extractor finds the SVGs of each `h2`/`h3` section, reads the axis
labels (numeric ticks, `HH:MM` time ticks, categorical state labels such as
`Idle/Search/Lock`), picks the data polyline, converts its pixel coordinates
to absolute positions by accumulating the SVG `transform` chain, and maps
them to values with linear fits on the tick positions.

    43	def parse_iso_utc(s: str):
    44	    """Return a timezone aware :class:`datetime` from a ``YYYY-MM-DD HH:MM:SSZ`` string.
    45	
    46	    Parameters
    47	    ----------
    48	    s : str
    49	        Timestamp in the strict ISO format used in the HTML reports.
    50	
    51	    Returns
    52	    -------
    53	    datetime | None
    54	        ``datetime`` object in UTC or ``None`` if the input is missing or
    55	        does not match the expected pattern.
    56	
    57	    Notes
    58	    -----
    59	    The function validates the string with a regular expression before
    60	    constructing the ``datetime`` object. Only the ``Z`` (Zulu/UTC) timezone
    61	    designator is accepted.
    62	    """
    63	    if not s:
    64	        return None  # Empty field – nothing to parse
    65	    s = s.strip()  # Remove leading/trailing whitespace
    66	
    67	    # Match date and time components with a regular expression. ``m`` is a
    68	    # ``re.Match`` object if the pattern is found; otherwise ``None``.
    69	    m = re.match(r"(\d{4}-\d{2}-\d{2})\s+(\d{2}):(\d{2}):(\d{2})Z", s)
    70	    if not m:
    71	        return None  # The string is not in the expected ISO format
    72	
    73	    # Split the first capture group (YYYY-MM-DD) into integers using ``map``
    74	    # and unpack the remaining groups for hours, minutes and seconds.
    75	    y, mo, d = map(int, m.group(1).split("-"))
    76	    hh, mm, ss = int(m.group(2)), int(m.group(3)), int(m.group(4))
    77	
    78	    # Create and return an aware ``datetime`` with the UTC timezone.
    79	    return datetime(y, mo, d, hh, mm, ss, tzinfo=timezone.utc)

    82	def parse_transforms(transform: str):
    83	    """Collapse an SVG ``transform`` chain into scale and translation factors.
    84	
    85	    Parameters
    86	    ----------
    87	    transform : str
    88	        Value of the ``transform`` attribute, e.g. ``"scale(2) translate(3,4)"``.
    89	
    90	    Returns
    91	    -------
    92	    tuple[float, float, float, float]
    93	        Aggregate scale ``(sx, sy)`` and translation ``(tx, ty)`` values.
    94	
    95	    Explanation
    96	    -----------
    97	    SVG allows multiple ``scale`` and ``translate`` operations to be combined
    98	    in a single string.  This function walks through each transformation in
    99	    order and accumulates the resulting scale and translation.  Only these two
   100	    operations are handled because the charts produced by the MEOS report use
   101	    a simple transformation chain.
   102	    """
   103	    sx, sy, tx, ty = 1.0, 1.0, 0.0, 0.0  # Start with the identity transform
   104	    if not transform:
   105	        return sx, sy, tx, ty  # Nothing to parse → return defaults
   106	
   107	    # ``re.finditer`` yields each ``scale`` or ``translate`` call. Captured
   108	    # arguments are later split into a Python list of numbers.
   109	    for m in re.finditer(r"(translate|scale)\(\s*([^)]+)\)", transform):
   110	        kind = m.group(1)  # Either 'scale' or 'translate'
   111	        # ``re.split`` handles comma- or space-separated numbers. ``list``
   112	        # comprehension converts each token to ``float``.
   113	        args = [float(v) for v in re.split(r"[, \t]+", m.group(2).strip()) if v]
   114	        if kind == "scale":
   115	            # Apply scaling. If only one value is supplied, it scales both axes.
   116	            if len(args) == 1:
   117	                sx *= args[0]; sy *= args[0]
   118	            else:
   119	                sx *= args[0]; sy *= args[1]
   120	        else:  # ``translate`` case
   121	            # Translation accepts one or two numbers (x and optionally y).
   122	            if len(args) == 1:
   123	                tx += args[0]
   124	            else:
   125	                tx += args[0]; ty += args[1]
   126	    return sx, sy, tx, ty

   129	def cumulative_transform(tag):
   130	    """Compute the combined transform of an SVG element and its ancestors.
   131	
   132	    Parameters
   133	    ----------
   134	    tag : bs4.element.Tag
   135	        Current SVG node whose effective transform is required.
   136	
   137	    Returns
   138	    -------
   139	    tuple[float, float, float, float]
   140	        Overall scale ``(Sx, Sy)`` and translation ``(Tx, Ty)`` factors.
   141	
   142	    Details
   143	    -------
   144	    SVG applies parent transforms to child elements.  The function therefore
   145	    walks up the DOM tree collecting ``transform`` attributes, then applies
   146	    them from outermost to innermost.  A simple loop is used instead of
   147	    recursion to avoid building deep call stacks.
   148	    """
   149	    # Accumulators start as an identity transform: scale 1 and translation 0.
   150	    Sx, Sy, Tx, Ty = 1.0, 1.0, 0.0, 0.0
   151	    chain = []  # Will store transform strings encountered on the path to root
   152	    cur = tag
   153	
   154	    # Traverse ancestors and collect their ``transform`` attributes. The
   155	    # ``getattr`` guard ensures compatibility with objects that may not be
   156	    # BeautifulSoup ``Tag`` instances.
   157	    while cur is not None and getattr(cur, "name", None) is not None:
   158	        tr = cur.get("transform")
   159	        if tr:
   160	            chain.append(tr)
   161	        cur = cur.parent  # Move one level up the tree
   162	
   163	    # Apply transforms from root to current element. ``reversed`` produces a
   164	    # generator that yields items in reverse order without creating a copy.
   165	    for tr in reversed(chain):
   166	        sx, sy, tx, ty = parse_transforms(tr)
   167	        # First transform existing translation, then accumulate new offsets.
   168	        Tx = sx * Tx + tx
   169	        Ty = sy * Ty + ty
   170	        # Update the global scale factors.
   171	        Sx *= sx
   172	        Sy *= sy
   173	    return Sx, Sy, Tx, Ty

   176	def apply_tr(x, y, Sx, Sy, Tx, Ty):
   177	    """Apply scale and translation factors to a point.
   178	
   179	    Parameters
   180	    ----------
   181	    x, y : float
   182	        Coordinates in the local SVG space.
   183	    Sx, Sy, Tx, Ty : float
   184	        Scale and translation returned by :func:`cumulative_transform`.
   185	
   186	    Returns
   187	    -------
   188	    tuple[float, float]
   189	        The transformed point in absolute pixel coordinates.
   190	    """
   191	    # Simple arithmetic uses Python's float type. Returning a tuple allows
   192	    # callers to unpack the two coordinates at once.
   193	    return Sx * x + Tx, Sy * y + Ty

   196	def parse_path_subpaths(d_attr: str):
   197	    """Split an SVG ``path`` definition into absolute subpaths.
   198	
   199	    Parameters
   200	    ----------
   201	    d_attr : str
   202	        The content of the ``d`` attribute from a ``<path>`` element.
   203	
   204	    Returns
   205	    -------
   206	    list[list[tuple[float, float]]]
   207	        Each inner list contains ``(x, y)`` pairs describing one continuous
   208	        polyline. A new subpath starts whenever an ``M`` or ``m`` command is
   209	        encountered.
   210	
   211	    Description
   212	    -----------
   213	    Only the commands ``M/m`` (move), ``L/l`` (line), ``H/h`` (horizontal) and
   214	    ``V/v`` (vertical) are supported because the gnuplot output embedded in the
   215	    report uses these primitives exclusively.  Numbers are converted to
   216	    ``float`` for easier numeric processing.
   217	    """
   218	    # Extract drawing commands and numbers. The regular expression yields a
   219	    # list of tuples where only one item of each tuple is non-empty.
   220	    tokens = re.findall(r"([MmLlHhVv])|([-+]?\d*\.?\d+(?:e[-+]?\d+)?)", d_attr or "")
   221	
   222	    flat = []
   223	    for a, b in tokens:
   224	        if a:
   225	            flat.append(a)  # SVG command as a string
   226	        else:
   227	            flat.append(float(b))  # Coordinate or length as Python float
   228	
   229	    # ``subpaths`` collects individual polylines; ``current`` tracks the one
   230	    # currently being built. ``x`` and ``y`` hold the cursor position.
   231	    subpaths = []
   232	    x = y = 0.0
   233	    cmd = None
   234	    i = 0
   235	    current = []
   236	
   237	    def flush():
   238	        """Append ``current`` polyline to ``subpaths`` if it has at least two points."""
   239	        nonlocal current
   240	        if len(current) >= 2:
   241	            subpaths.append(current)
   242	        current = []  # Reset for the next subpath
   243	
   244	    # Iterate through the token list using an index ``i`` so we can look ahead
   245	    # when commands require multiple numeric parameters.
   246	    while i < len(flat):
   247	        t = flat[i]
   248	        if isinstance(t, str):
   249	            # ``t`` is a command letter. Store it and, for ``M/m``, close the
   250	            # previous subpath.
   251	            cmd = t
   252	            if cmd in ("M", "m"):
   253	                flush()
   254	            i += 1
   255	            continue
   256	
   257	        # At this point ``t`` is a numeric value associated with the last
   258	        # command seen.
   259	        if cmd == "M":  # Absolute move-to command
   260	            if i + 1 < len(flat) and not isinstance(flat[i + 1], str):
   261	                x, y = flat[i], flat[i + 1]  # Set new absolute position
   262	                current = [(x, y)]  # Start a new subpath list
   263	                i += 2
   264	            else:
   265	                i += 1  # Malformed data; skip value
   266	        elif cmd == "m":  # Relative move-to command
   267	            if i + 1 < len(flat) and not isinstance(flat[i + 1], str):
   268	                x += flat[i]; y += flat[i + 1]  # Update position relative to current point
   269	                current = [(x, y)]
   270	                i += 2
   271	            else:
   272	                i += 1
   273	        elif cmd == "L":  # Absolute line-to command
   274	            if i + 1 < len(flat) and not isinstance(flat[i + 1], str):
   275	                x, y = flat[i], flat[i + 1]
   276	                current.append((x, y))  # Append point to current polyline
   277	                i += 2
   278	            else:
   279	                i += 1
   280	        elif cmd == "l":  # Relative line-to command
   281	            if i + 1 < len(flat) and not isinstance(flat[i + 1], str):
   282	                x += flat[i]; y += flat[i + 1]
   283	                current.append((x, y))
   284	                i += 2
   285	            else:
   286	                i += 1
   287	        elif cmd == "H":  # Absolute horizontal line
   288	            x = flat[i]; current.append((x, y)); i += 1
   289	        elif cmd == "h":  # Relative horizontal line
   290	            x += flat[i]; current.append((x, y)); i += 1
   291	        elif cmd == "V":  # Absolute vertical line
   292	            y = flat[i]; current.append((x, y)); i += 1
   293	        elif cmd == "v":  # Relative vertical line
   294	            y += flat[i]; current.append((x, y)); i += 1
   295	        else:
   296	            i += 1  # Unsupported command; skip token
   297	
   298	    flush()
   299	    return subpaths

   302	NUM_TICK_RE = re.compile(
   303	    r"([-+]?(?:\d+(?:[.,]\d+)?|[.,]\d+)(?:[eE][-+]?\d+)?)\s*([kMGTPmuµn])?\s*(?:dB|°|deg)?"
   304	)
   305	SI_PREFIX = {"k": 1e3, "M": 1e6, "G": 1e9, "T": 1e12, "P": 1e15, "m": 1e-3, "u": 1e-6, "µ": 1e-6, "n": 1e-9}

   308	def parse_tick_value(text):
   309	    """Return the numeric value of a tick label (e.g. ``"-10"``, ``"2.5 dB"``, ``"10G"``), or NaN."""
   310	    m = NUM_TICK_RE.fullmatch(str(text).strip())
   311	    if not m:
   312	        return np.nan
   313	    value = float(m.group(1).replace(",", "."))
   314	    return value * SI_PREFIX.get(m.group(2), 1.0) if m.group(2) else value

   317	def _time_label_seconds(text):
   318	    """Seconds of day for ``HH:MM`` / ``HH:MM:SS`` labels."""
   319	    parts = [int(p) for p in str(text).split(":")]
   320	    return parts[0] * 3600 + parts[1] * 60 + (parts[2] if len(parts) > 2 else 0)

   323	def _state_axis_labels(other_rows, x_axis_left=None):
   324	    """Pick the categorical Y-axis labels (e.g. Idle/Search/Lock) among non-numeric texts.
   325	
   326	    Axis labels share the same X column and sit at different heights; legend
   327	    entries and axis titles are isolated texts and are therefore ignored.
   328	    """
   329	    groups = {}
   330	    for row in other_rows:
   331	        if x_axis_left is not None and row["x_px"] > x_axis_left:
   332	            continue
   333	        groups.setdefault(round(row["x_px"], 0), []).append(row)
   334	    best = []
   335	    for _, rows in sorted(groups.items()):
   336	        if len({round(r["y_px"], 1) for r in rows}) >= 2 and len(rows) > len(best):
   337	            best = rows
   338	    return best

   341	def svg_axes_from_ticks(svg):
   342	    """
   343	    Estrae tick (label testo) e posizioni pixel assolute.
   344	    Definisce il riquadro assi:
   345	      - X: min/max posizione pixel dei tick orari (HH:MM o HH:MM:SS)
   346	      - Y: min/max posizione pixel dei tick numerici
   347	    Le etichette testuali dell'asse Y (es. Idle/Search/Lock) sono marcate "state".
   348	    """
   349	    rows = []
   350	    other_rows = []
   351	    for t in svg.find_all("text"):
   352	        content = (t.get_text() or "").strip()
   353	        if not content:
   354	            continue
   355	        is_num = NUM_TICK_RE.fullmatch(content) is not None
   356	        is_time = re.fullmatch(r"\d{2}:\d{2}(?::\d{2})?", content) is not None
   357	        Sx, Sy, Tx, Ty = cumulative_transform(t)
   358	        x_px, y_px = apply_tr(0.0, 0.0, Sx, Sy, Tx, Ty)
   359	        if not (is_num or is_time):
   360	            if re.search(r"[A-Za-z]", content):
   361	                other_rows.append({"text": content, "x_px": x_px, "y_px": y_px, "kind": "state"})
   362	            continue
   363	        rows.append({"text": content, "x_px": x_px, "y_px": y_px, "kind": "num" if is_num else "time"})
   364	
   365	    time_x = [r["x_px"] for r in rows if r["kind"] == "time"]
   366	    rows.extend(_state_axis_labels(other_rows, min(time_x) if time_x else None))
   367	
   368	    ticks = pd.DataFrame(rows, columns=["text", "x_px", "y_px", "kind"])
   369	
   370	    if ticks.empty:
   371	        return ticks, (None, None, None, None)
   372	
   373	    x_ticks = ticks.loc[ticks["kind"] == "time", "x_px"]
   374	    y_ticks = ticks.loc[ticks["kind"] == "num", "y_px"]
   375	    if y_ticks.empty:
   376	        y_ticks = ticks.loc[ticks["kind"] == "state", "y_px"]
   377	
   378	    x_tick_px_min = x_ticks.min() if not x_ticks.empty else None
   379	    x_tick_px_max = x_ticks.max() if not x_ticks.empty else None
   380	    y_tick_px_min = y_ticks.min() if not y_ticks.empty else None
   381	    y_tick_px_max = y_ticks.max() if not y_ticks.empty else None
   382	
   383	    return ticks, (x_tick_px_min, x_tick_px_max, y_tick_px_min, y_tick_px_max)

   386	def _load_object_svg(data: str, base_dir=None):
   387	    """Load the SVG referenced by an ``<object data=...>`` (base64, URL or local path)."""
   388	    m = re.match(r"^data:image/svg\+xml(;charset=[^;]+)?;base64,(.*)$", data, re.I | re.S)
   389	    if m:  # Base64 inline data
   390	        svg_bytes = base64.b64decode(m.group(2))
   391	    elif data.startswith(("http://", "https://")):  # Remote file
   392	        with urllib.request.urlopen(data, timeout=30) as resp:
   393	            svg_bytes = resp.read()
   394	    elif data:  # Local file path, relative to the HTML report
   395	        path = Path(data)
   396	        if not path.is_absolute() and base_dir is not None:
   397	            path = Path(base_dir) / path
   398	        svg_bytes = path.read_bytes()
   399	    else:
   400	        return None
   401	    try:
   402	        svg_soup = BeautifulSoup(svg_bytes, "xml")
   403	    except FeatureNotFound:
   404	        logger.warning(
   405	            "lxml parser not found; falling back to html.parser. Install lxml for full XML support."
   406	        )
   407	        svg_soup = BeautifulSoup(svg_bytes, "html.parser")
   408	    return svg_soup.svg

   411	def collect_section_svgs(hdr, base_dir=None, load_objects=True):
   412	    """Return the SVG charts between *hdr* and the next h2/h3 header.
   413	
   414	    Inline SVGs without any text (icons, decorations) are ignored: a chart
   415	    always has axis labels.
   416	    """
   417	    svgs = []
   418	    if hdr is None:
   419	        return svgs
   420	    for el in hdr.next_elements:
   421	        name = getattr(el, "name", None)
   422	        if name in ("h2", "h3"):
   423	            break
   424	        if name == "svg":
   425	            if el.find("text") is not None:
   426	                svgs.append(el)
   427	        elif name == "object" and el.get("type") == "image/svg+xml":
   428	            if not load_objects:
   429	                svgs.append(el)
   430	                continue
   431	            data = el.get("data", "")
   432	            try:
   433	                svg = _load_object_svg(data, base_dir)
   434	                if svg is not None:
   435	                    svgs.append(svg)
   436	            except Exception as exc:
   437	                logger.warning("Failed to load SVG from %s: %s", data[:80], exc)
   438	    return svgs

   441	def extract_curve_for_header(hdr, base_dir=None):
   442	    """
   443	    Per una sezione (h2/h3) già individuata, raccoglie gli SVG sottostanti fino
   444	    al prossimo h2/h3 e sceglie il sottopercorso dati migliore (massimo numero
   445	    di punti dentro il riquadro assi).
   446	    """
   447	    svgs = collect_section_svgs(hdr, base_dir)
   448	    if not svgs:
   449	        return pd.DataFrame(), pd.DataFrame()
   450	
   451	    # Scegli lo svg con più gruppi "gnuplot_plot_*"
   452	    def count_groups(s):
   453	        return len([g for g in s.find_all("g") if (g.get("id") or "").startswith("gnuplot_plot_")])
   454	
   455	    best_svg = max(svgs, key=count_groups)
   456	    ticks, axes = svg_axes_from_ticks(best_svg)
   457	    x_min_tick, x_max_tick, y_min_tick, y_max_tick = axes
   458	
   459	    best_pts = []
   460	    best_score = -1
   461	
   462	    groups = [
   463	        g
   464	        for g in best_svg.find_all("g")
   465	        if (g.get("id") or "").startswith("gnuplot_plot_") and (g.find("path") or g.find("polyline"))
   466	    ]
   467	    if not groups:
   468	        groups = [g for g in best_svg.find_all("g") if g.find("path") or g.find("polyline")]
   469	    def has_missing_axes(values):
   470	        return any(v is None or (isinstance(v, float) and np.isnan(v)) for v in values)
   471	
   472	    for g in groups:
   473	        # PATH: split in subpath e valuta punti dentro assi
   474	        for p in g.find_all("path"):
   475	            d = p.get("d")
   476	            if not d:
   477	                continue
   478	            Sx, Sy, Tx, Ty = cumulative_transform(p)
   479	            for sp in parse_path_subpaths(d):
   480	                pts = [apply_tr(x, y, Sx, Sy, Tx, Ty) for x, y in sp]
   481	                if has_missing_axes((x_min_tick, x_max_tick, y_min_tick, y_max_tick)):
   482	                    score = len(pts)
   483	                else:
   484	                    m = 2.0
   485	                    score = sum(
   486	                        (x_min_tick - m <= x <= x_max_tick + m) and
   487	                        (y_min_tick - m <= y <= y_max_tick + m)
   488	                        for x, y in pts
   489	                    )
   490	                if score > best_score:
   491	                    best_pts = pts
   492	                    best_score = score
   493	
   494	        # POLYLINE: fallback
   495	        for pl in g.find_all("polyline"):
   496	            raw = (pl.get("points") or "").strip()
   497	            if not raw:
   498	                continue
   499	            raw = re.sub(r"\s+", " ", raw)
   500	            pairs = re.findall(
   501	                r"([-+]?\d*\.?\d+(?:e[-+]?\d+)?)\s*,\s*([-+]?\d*\.?\d+(?:e[-+]?\d+)?)",
   502	                raw
   503	            )
   504	            pts_local = [(float(x), float(y)) for x, y in pairs]
   505	            Sx, Sy, Tx, Ty = cumulative_transform(pl)
   506	            pts = [apply_tr(x, y, Sx, Sy, Tx, Ty) for x, y in pts_local]
   507	
   508	            if has_missing_axes((x_min_tick, x_max_tick, y_min_tick, y_max_tick)):
   509	                score = len(pts)
   510	            else:
   511	                m = 2.0
   512	                score = sum(
   513	                    (x_min_tick - m <= x <= x_max_tick + m) and
   514	                    (y_min_tick - m <= y <= y_max_tick + m)
   515	                    for x, y in pts
   516	                )
   517	            if score > best_score:
   518	                best_pts = pts
   519	                best_score = score
   520	
   521	    curve_px = pd.DataFrame(best_pts, columns=["x_px", "y_px"])
   522	    return curve_px, ticks

   525	def extract_curves_for_header(hdr, base_dir=None):
   526	    """Extract multiple candidate curves for a header (multi-series friendly)."""
   527	    svgs = collect_section_svgs(hdr, base_dir)

   531	    candidates = []

   614	def _time_tick_fit(ticks: pd.DataFrame, start_dt: datetime):
   615	    """Fit x_px → seconds from *start_dt* using the HH:MM(:SS) tick labels.
   616	
   617	    Returns ``(a, b)`` such that ``t_sec_rel = a * x_px + b``, or ``None``
   618	    when fewer than two distinct time ticks are available.
   619	    """
   620	    if ticks is None or ticks.empty or start_dt is None:
   621	        return None
   622	    tt = ticks[ticks["kind"] == "time"].sort_values("x_px")
   623	    if tt["x_px"].round(2).nunique() < 2:
   624	        return None
   625	    secs = tt["text"].apply(_time_label_seconds).to_numpy(dtype=float)
   626	    # Unwrap midnight crossings (23:59 → 00:00).
   627	    secs = secs + 86400.0 * np.concatenate([[0], np.cumsum(np.diff(secs) < 0)])
   628	    a, b = np.polyfit(tt["x_px"].to_numpy(dtype=float), secs, 1)
   629	    if a <= 0:
   630	        return None
   631	    # Express the fit relative to start_dt, choosing the day closest to it.
   632	    start_sod = start_dt.hour * 3600 + start_dt.minute * 60 + start_dt.second
   633	    b_rel = b - start_sod
   634	    first = a * float(tt["x_px"].iloc[0]) + b_rel
   635	    b_rel -= 86400.0 * round(first / 86400.0)
   636	    return a, b_rel

   639	def map_x_to_time(df: pd.DataFrame, start_dt: datetime, stop_dt: datetime, ticks: pd.DataFrame = None):
   640	    """Mappa x_px in tempo assoluto.
   641	
   642	    Se il grafico ha almeno due tick orari (HH:MM) la posizione viene
   643	    convertita con un fit lineare sui tick; altrimenti la curva viene stirata
   644	    sull'intervallo Start→Stop (in secondi).
   645	    """
   646	    fit = _time_tick_fit(ticks, start_dt)
   647	    if df.empty or not start_dt or (not stop_dt and fit is None):
   648	        df["t_sec_rel"] = np.nan
   649	        df["time_HH:MM:SS"] = None
   650	        df["time_iso_utc"] = None
   651	        return df
   652	
   653	    x_min = df["x_px"].min()
   654	    x_max = df["x_px"].max()
   655	    if fit is not None:
   656	        df["t_sec_rel"] = fit[0] * df["x_px"] + fit[1]
   657	    elif x_max == x_min:
   658	        df["t_sec_rel"] = 0.0
   659	    else:
   660	        dur = (stop_dt - start_dt).total_seconds()
   661	        df["t_sec_rel"] = (df["x_px"] - x_min) / (x_max - x_min) * dur
   662	    df["time_iso_utc"] = df["t_sec_rel"].apply(
   663	        lambda s: (start_dt + timedelta(seconds=float(s))).strftime("%Y-%m-%d %H:%M:%S")
   664	    )
   665	    df["time_HH:MM:SS"] = df["t_sec_rel"].apply(
   666	        lambda s: (start_dt + timedelta(seconds=float(s))).strftime("%H:%M:%S")
   667	    )
   668	    return df

   671	def map_y_from_ticks(df: pd.DataFrame, ticks: pd.DataFrame, colname: str):
   672	    """Fit lineare: y_px → valore asse (da tick numerici)."""
   673	    if df.empty or ticks is None or ticks.empty:
   674	        df[colname] = np.nan
   675	        return df
   676	    y_ticks = ticks[ticks["kind"] == "num"].copy()
   677	    y_ticks["value"] = y_ticks["text"].apply(parse_tick_value)
   678	    y_ticks = y_ticks.dropna(subset=["value"])
   679	    if y_ticks["y_px"].round(2).nunique() >= 2:
   680	        Y = np.vstack([y_ticks["y_px"].values, np.ones(len(y_ticks))]).T
   681	        a, b = np.linalg.lstsq(Y, y_ticks["value"].values, rcond=None)[0]
   682	        df[colname] = a * df["y_px"] + b
   683	        return df
   684	
   685	    state_ticks = ticks[ticks["kind"] == "state"].sort_values("y_px", ascending=False)
   686	    if len(state_ticks) >= 2:
   687	        # Categorical axis (e.g. Idle/Search/Lock): snap each point to the
   688	        # nearest label. Value = level index from the bottom (0, 1, 2, ...),
   689	        # except for plain locked/unlocked axes which map to 1/0.
   690	        labels = state_ticks["text"].tolist()
   691	        levels = state_ticks["y_px"].to_numpy(dtype=float)
   692	        values = np.arange(len(labels), dtype=float)
   693	        is_unlock = [re.fullmatch(r"(?i)unlock(ed)?|no\s*lock|out\s*of\s*lock|loss\s*of\s*lock", s) is not None for s in labels]
   694	        is_lock = [re.fullmatch(r"(?i)lock(ed)?", s) is not None for s in labels]
   695	        if len(labels) == 2 and all(u or l for u, l in zip(is_unlock, is_lock)) and any(is_lock) and any(is_unlock):
   696	            values = np.array([0.0 if u else 1.0 for u in is_unlock])
   697	        nearest = np.abs(df["y_px"].to_numpy(dtype=float)[:, None] - levels[None, :]).argmin(axis=1)
   698	        df[colname] = values[nearest]
   699	        df[f"{colname}_state"] = [labels[i] for i in nearest]
   700	        return df
   701	
   702	    if "lock" in colname.lower() and not df.empty:
   703	        threshold = float(df["y_px"].median())
   704	        df[colname] = (df["y_px"] <= threshold).astype(int)
   705	        return df
   706	
   707	    df[colname] = np.nan
   708	    return df

   719	def _svg_series_color(*nodes):
   720	    """Extract the most relevant SVG stroke/fill color from a path/polyline/group."""
   721	    def read_color(node):
   722	        if node is None:
   723	            return None
   724	        for attr in ("stroke", "fill"):
   725	            val = (node.get(attr) or "").strip()
   726	            if val and val.lower() != "none":
   727	                return val
   728	        style = node.get("style") or ""
   729	        for key in ("stroke", "fill"):
   730	            m = re.search(rf"{key}\s*:\s*([^;]+)", style, flags=re.I)
   731	            if m:
   732	                val = m.group(1).strip()
   733	                if val and val.lower() != "none":
   734	                    return val
   735	        return None
   736	
   737	    for node in nodes:
   738	        color = read_color(node)
   739	        if color:
   740	            return color
   741	    return None

   744	def _color_family(color: str):
   745	    """Classify a color as green/purple when possible."""
   746	    if not color:
   747	        return None
   748	    c = color.strip().lower()
   749	    if any(k in c for k in ("green", "lime", "chartreuse")):
   750	        return "green"
   751	    if any(k in c for k in ("purple", "violet", "magenta", "fuchsia")):
   752	        return "purple"
   753	    m = re.fullmatch(r"#?([0-9a-f]{6})", c)
   754	    if m:
   755	        hx = m.group(1)
   756	        r = int(hx[0:2], 16)
   757	        g = int(hx[2:4], 16)
   758	        b = int(hx[4:6], 16)
   759	        if g >= max(r, b) + 20:
   760	            return "green"
   761	        if (r + b) / 2 >= g + 20:
   762	            return "purple"
   763	    m = re.fullmatch(r"rgb\(\s*(\d+)\s*,\s*(\d+)\s*,\s*(\d+)\s*\)", c)
   764	    if m:
   765	        r, g, b = map(int, m.groups())
   766	        if g >= max(r, b) + 20:
   767	            return "green"
   768	        if (r + b) / 2 >= g + 20:
   769	            return "purple"
   770	    return None

   793	def derive_orbit_filename(soup: BeautifulSoup):
   794	    """
   795	    Ricava (prefix, orbit_no) dall'HTML, senza fallback fissi.
   796	    - orbit_no: 'orbit 1234' / 'Orbit: 1234'
   797	    - prefix: prova in tabella "Session" (Spacecraft/Satellite/Mission/Name/Platform/...),
   798	              quindi <title> e header h1/h2/h3, infine pattern tipo 'AWS-PFM' nel testo.
   799	      Se non si trova nulla, prefix=None.
   800	    """
   801	    txt = soup.get_text(" ", strip=True)
   802	
   803	    # Orbit number
   804	    m = re.search(r"\borbit\s*[:#]?\s*(\d{1,7})\b", txt, flags=re.I)
   805	    orbit_no = m.group(1) if m else None
   806	
   807	    candidates = []
   808	
   809	    # 1) Dalla tabella Session
   810	    h2 = soup.find(id="_session")
   811	    if h2:
   812	        tbl = h2.find_next("table")
   813	        if tbl:
   814	            for row in tbl.find_all("tr"):
   815	                cells = row.find_all(["td", "th"])
   816	                if len(cells) < 2:
   817	                    continue
   818	                key = cells[0].get_text(" ", strip=True).lower()
   819	                val = cells[1].get_text(" ", strip=True)
   820	                if not val:
   821	                    continue
   822	                if any(k in key for k in (
   823	                    "spacecraft", "satellite", "mission", "name", "platform", "asset", "receiver", "modem"
   824	                )):
   825	                    candidates.append(val)
   826	
   827	    # 2) <title> + headers
   828	    if soup.title and soup.title.get_text(strip=True):
   829	        candidates.append(soup.title.get_text(" ", strip=True))
   830	    for hdr in soup.find_all(["h1", "h2", "h3"]):
   831	        t = hdr.get_text(" ", strip=True)
   832	        if t:
   833	            candidates.append(t)
   834	
   835	    # 3) pattern tipo AWS-PFM da testo generale
   836	    m2 = re.search(r"\b([A-Z]{2,}(?:-[A-Z0-9]{2,})+)\b", txt)
   837	    if m2:
   838	        candidates.append(m2.group(1))
   839	
   840	    prefix = None
   841	    for raw in candidates:
   842	        cleaned = re.sub(r"[^A-Za-z0-9_-]+", " ", raw).strip()
   843	        m = re.search(r"\b([A-Za-z0-9]+(?:[-_][A-Za-z0-9]+)+)\b", cleaned)
   844	        if not m:
   845	            m = re.search(r"\b([A-Z0-9]{3,})\b", cleaned)
   846	        if m:
   847	            prefix = m.group(1)
   848	            break
   849	
   850	    return prefix, orbit_no

   868	        if stable[i - 1] == 1 and stable[i] == 0 and stable[i + 1] == 1
   869	    )

   896	def _infer_az_el_from_antenna(section_frames: dict):
   897	    """Fallback: infer az/el from multiple antenna-like series when labels are generic."""
   898	    antenna = []
   899	    for ycol, df in section_frames.items():
   900	        n = _normalized_label(ycol)
   901	        if "antenna" not in n:
   902	            continue
   903	        if ycol not in df or df.empty:
   904	            continue
   905	        vals = pd.to_numeric(df[ycol], errors="coerce").dropna()
   906	        if vals.empty:
   907	            continue
   908	        antenna.append((ycol, df, float(vals.median()), float(vals.max()), float(vals.min())))
   909	
   910	    if len(antenna) < 2:
   911	        return None, None, None, None
   912	
   913	    # prefer a high-span/high-magnitude curve as azimuth and lower-magnitude as elevation
   914	    az_item = max(antenna, key=lambda t: (t[3] - t[4], t[3]))
   915	    el_candidates = [a for a in antenna if a[0] != az_item[0]]
   916	    el_item = min(el_candidates, key=lambda t: t[3])
   917	    return az_item[0], az_item[1], el_item[0], el_item[1]

   958	
   959	    token_map = {

   993	def _align_metric_with_az_el(metric: pd.DataFrame, az: pd.DataFrame, el: pd.DataFrame):
   994	    """Align metric samples with azimuth/elevation on common time interval."""
   995	    # common overlap window
   996	    t0 = max(float(metric["t_sec_rel"].min()), float(az["t_sec_rel"].min()), float(el["t_sec_rel"].min()))
   997	    t1 = min(float(metric["t_sec_rel"].max()), float(az["t_sec_rel"].max()), float(el["t_sec_rel"].max()))
   998	    if t1 <= t0:
   999	        return pd.DataFrame()
  1000	
  1001	    metric = metric[(metric["t_sec_rel"] >= t0) & (metric["t_sec_rel"] <= t1)].copy()
  1002	    az = az[(az["t_sec_rel"] >= t0) & (az["t_sec_rel"] <= t1)].copy()
  1003	    el = el[(el["t_sec_rel"] >= t0) & (el["t_sec_rel"] <= t1)].copy()
  1004	    if metric.empty or az.empty or el.empty:
  1005	        return pd.DataFrame()
  1006	
  1007	    # Deduplicate and sort by time.
  1008	    metric = metric.sort_values("t_sec_rel").groupby("t_sec_rel", as_index=False)["metric"].median()
  1009	    az = az.sort_values("t_sec_rel").drop_duplicates("t_sec_rel")
  1010	    el = el.sort_values("t_sec_rel").drop_duplicates("t_sec_rel")
  1011	    if len(metric) < 2 or len(az) < 2 or len(el) < 2:
  1012	        return pd.DataFrame()
  1013	
  1014	    # Build a regular time base to avoid clustered/jagged point clouds.
  1015	    n_samples = int(np.clip(max(len(metric), 200), 120, 800))
  1016	    t = np.linspace(t0, t1, n_samples)
  1017	
  1018	    metric_t = metric["t_sec_rel"].to_numpy(dtype=float)
  1019	    metric_v = metric["metric"].to_numpy(dtype=float)
  1020	    metric_interp = np.interp(t, metric_t, metric_v)
  1021	
  1022	    az_t = az["t_sec_rel"].to_numpy(dtype=float)
  1023	    el_t = el["t_sec_rel"].to_numpy(dtype=float)
  1024	
  1025	    # interpolate azimuth with angular continuity: unwrap in radians, then wrap back.
  1026	    az_rad = np.deg2rad(az["azimuth"].to_numpy(dtype=float))
  1027	    az_unwrapped = np.unwrap(az_rad)
  1028	    az_interp_unwrapped = np.interp(t, az_t, az_unwrapped)
  1029	    az_interp = np.rad2deg(az_interp_unwrapped) % 360.0
  1030	
  1031	    # linear interpolation for elevation.
  1032	    el_interp = np.interp(t, el_t, el["elevation"].to_numpy(dtype=float))
  1033	
  1034	    aligned = pd.DataFrame({
  1035	        "t_sec_rel": t,
  1036	        "metric": metric_interp,
  1037	        "azimuth": az_interp,
  1038	        "elevation": el_interp,
  1039	    })
  1040	    aligned = aligned.dropna(subset=["metric", "azimuth", "elevation"])
  1041	    return aligned

  1044	def _align_lock_state_to_times(lock_df: pd.DataFrame, t_values):
  1045	    """Align lock-state samples to the supplied time base using zero-order hold."""
  1046	    if lock_df is None or len(lock_df) == 0 or len(t_values) == 0:
  1047	        return np.array([], dtype=float)
  1048	
  1049	    lock = lock_df[["t_sec_rel", "lock_state"]].copy()
  1050	    lock["t_sec_rel"] = pd.to_numeric(lock["t_sec_rel"], errors="coerce")
  1051	    lock["lock_state"] = pd.to_numeric(lock["lock_state"], errors="coerce")
  1052	    lock = lock.dropna().sort_values("t_sec_rel").drop_duplicates("t_sec_rel", keep="last")
  1053	    if lock.empty:
  1054	        return np.array([], dtype=float)
  1055	
  1056	    t = np.asarray(t_values, dtype=float)
  1057	    pos = np.searchsorted(lock["t_sec_rel"].to_numpy(dtype=float), t, side="right") - 1
  1058	    lock_vals = np.full(len(t), np.nan, dtype=float)
  1059	    valid = pos >= 0
  1060	    if np.any(valid):
  1061	        states = lock["lock_state"].to_numpy(dtype=float)
  1062	        lock_vals[valid] = states[pos[valid]]
  1063	    return lock_vals

  1066	def _spherical_to_cartesian(az_deg, el_deg):
  1067	    """Convert azimuth/elevation angles to unit-sphere Cartesian coordinates."""
  1068	    az = np.deg2rad(np.asarray(az_deg, dtype=float))
  1069	    el = np.deg2rad(np.asarray(el_deg, dtype=float))
  1070	    r_xy = np.cos(el)
  1071	    x = r_xy * np.cos(az)
  1072	    y = r_xy * np.sin(az)
  1073	    z = np.sin(el)
  1074	    return x, y, z

  1080	def _split_azimuth_wrapped_segments(az_deg, el_deg, jump_threshold=180.0):
  1081	    """Split a track whenever wrapped azimuth jumps across the 0/360 boundary."""
  1082	    az = np.asarray(az_deg, dtype=float)
  1083	    el = np.asarray(el_deg, dtype=float)
  1084	    if len(az) != len(el) or len(az) == 0:
  1085	        return []
  1086	
  1087	    wrapped = np.mod(az, 360.0)
  1088	    split_points = np.where(np.abs(np.diff(wrapped)) > float(jump_threshold))[0] + 1
  1089	    chunks = []
  1090	    start = 0
  1091	    for stop in split_points:
  1092	        if stop - start >= 2:
  1093	            chunks.append((wrapped[start:stop], el[start:stop]))
  1094	        start = stop
  1095	    if len(wrapped) - start >= 2:
  1096	        chunks.append((wrapped[start:], el[start:]))
  1097	    return chunks

  1099	def _build_base_track(az: pd.DataFrame, el: pd.DataFrame, n_points: int = 500):
  1100	    """Build a smooth antenna base track from azimuth/elevation time series."""
  1101	    t0 = max(float(az["t_sec_rel"].min()), float(el["t_sec_rel"].min()))
  1102	    t1 = min(float(az["t_sec_rel"].max()), float(el["t_sec_rel"].max()))
  1103	    if t1 <= t0:
  1104	        return np.array([]), np.array([])
  1105	
  1106	    az_s = az.sort_values("t_sec_rel").drop_duplicates("t_sec_rel")
  1107	    el_s = el.sort_values("t_sec_rel").drop_duplicates("t_sec_rel")
  1108	    if len(az_s) < 2 or len(el_s) < 2:
  1109	        return np.array([]), np.array([])
  1110	
  1111	    t = np.linspace(t0, t1, n_points)
  1112	    az_t = az_s["t_sec_rel"].to_numpy(dtype=float)
  1113	    el_t = el_s["t_sec_rel"].to_numpy(dtype=float)
  1114	
  1115	    az_unwrapped = np.unwrap(np.deg2rad(az_s["azimuth"].to_numpy(dtype=float)))
  1116	    az_interp = np.rad2deg(np.interp(t, az_t, az_unwrapped))
  1117	    el_interp = np.interp(t, el_t, el_s["elevation"].to_numpy(dtype=float))
  1118	    el_interp = np.clip(el_interp, 0.0, 90.0)
  1119	    return az_interp, el_interp

  1579	def _numeric_tick_groups(ticks: pd.DataFrame):
  1580	    """Split numeric ticks into one or two X-side groups (for dual Y axes)."""
  1581	    if ticks is None or ticks.empty:
  1582	        return []
  1583	    num = ticks[ticks.get("kind") == "num"].copy()
  1584	    if num.empty:
  1585	        return []
  1586	    num["val"] = num["text"].apply(parse_tick_value)
  1587	    num = num.dropna(subset=["x_px", "y_px", "val"])
  1588	    if len(num) < 2:
  1589	        return [num]
  1590	
  1591	    x_sorted = np.sort(num["x_px"].to_numpy(dtype=float))
  1592	    x_diffs = np.diff(x_sorted)
  1593	    if len(x_diffs) == 0 or np.nanmax(x_diffs) <= 0:
  1594	        return [num]
  1595	
  1596	    split_at = int(np.nanargmax(x_diffs))
  1597	    gap = float(x_diffs[split_at])
  1598	    total_span = float(x_sorted[-1] - x_sorted[0])
  1599	    if total_span <= 0 or gap < max(8.0, 0.15 * total_span):
  1600	        return [num]
  1601	
  1602	    threshold = float((x_sorted[split_at] + x_sorted[split_at + 1]) / 2.0)
  1603	    left = num[num["x_px"] <= threshold]
  1604	    right = num[num["x_px"] > threshold]
  1605	    groups = []
  1606	    if len(left) >= 2:
  1607	        groups.append(left)
  1608	    if len(right) >= 2:
  1609	        groups.append(right)
  1610	    if not groups:
  1611	        groups.append(num)
  1612	    return groups

  1648	    """Ensure curve is single-valued over x (time axis) by collapsing duplicate x samples."""

  1682	def _regularize_antenna_series(df: pd.DataFrame, az_col: str, el_col: str):
  1683	    """Regularize antenna az/el time series to reduce extraction jitter."""
  1684	    out = df.copy()
  1685	    out = out.sort_values("t_sec_rel")
  1686	
  1687	    # Collapse duplicated/near-duplicated timestamps by median value.
  1688	    out["t_key"] = out["t_sec_rel"].round(3)
  1689	    agg = out.groupby("t_key", as_index=False).agg({
  1690	        "t_sec_rel": "median",
  1691	        "time_HH:MM:SS": "first",
  1692	        "time_iso_utc": "first",
  1693	        "x_px_az": "median",
  1694	        "y_px_az": "median",
  1695	        az_col: "median",
  1696	        "x_px_el": "median",
  1697	        "y_px_el": "median",
  1698	        el_col: "median",
  1699	    })
  1700	
  1701	    az = pd.to_numeric(agg[az_col], errors="coerce").to_numpy(dtype=float)
  1702	    el = pd.to_numeric(agg[el_col], errors="coerce").to_numpy(dtype=float)
  1703	    if len(agg) < 8:
  1704	        return agg.drop(columns=["t_key"], errors="ignore")
  1705	
  1706	    # Smooth elevation with piecewise monotonic profile (up then down).
  1707	    peak = int(np.nanargmax(el)) if np.isfinite(el).any() else len(el) // 2
  1708	    el_up = np.maximum.accumulate(el[: peak + 1])
  1709	    el_dn = np.minimum.accumulate(el[peak:])
  1710	    el_s = np.concatenate([el_up, el_dn[1:]]) if len(el_dn) > 1 else el_up
  1711	    el_s = np.clip(el_s, 0.0, 90.0)
  1712	
  1713	    # Smooth azimuth as mostly monotonic in unwrapped space.
  1714	    az_u = np.rad2deg(np.unwrap(np.deg2rad(az)))
  1715	    direction = np.nanmedian(np.diff(az_u))
  1716	    if np.isnan(direction):
  1717	        direction = 0.0
  1718	    if direction >= 0:
  1719	        az_s = np.maximum.accumulate(az_u)
  1720	    else:
  1721	        az_s = np.minimum.accumulate(az_u)
  1722	    az_s = np.mod(az_s, 360.0)
  1723	
  1724	    agg[az_col] = az_s
  1725	    agg[el_col] = el_s
  1726	    return agg.drop(columns=["t_key"], errors="ignore")

### Explanation
- **Lines 1-20:** File header: what is extracted, output file name, standalone usage and dependencies.
- **Lines 21-32:** Imports. `pathlib.Path` for paths, `argparse` for the CLI, `re` for regular expressions, `datetime` for time handling, `logging`, `base64`/`urllib.request` to load SVGs embedded in `<object>` tags, `numpy`/`pandas` for numeric and tabular data, `BeautifulSoup` for HTML/SVG parsing.

**SVG geometry**
- **Lines 43-79 `parse_iso_utc`:** Parses the report's `YYYY-MM-DD HH:MM:SSZ` timestamps into timezone-aware `datetime` objects (`None` when missing or malformed).
- **Lines 82-126 `parse_transforms`:** Collapses a `transform` attribute (`scale(...)`, `translate(...)`) into one scale and one translation per axis.
- **Lines 129-173 `cumulative_transform`:** Walks up the DOM collecting the `transform` of every ancestor and composes them from the root down: the result maps local coordinates to absolute pixels.
- **Lines 176-193 `apply_tr`:** Applies that scale/translation to a point.
- **Lines 196-299 `parse_path_subpaths`:** Tokenises the `d` attribute of a `<path>` (commands `M/m`, `L/l`, `H/h`, `V/v`, the ones gnuplot emits) into separate polylines; a new subpath starts at every move-to, so the legend sample and the data curve come out as different subpaths.

**Axis labels**
- **Lines 308-314 `parse_tick_value`:** Numeric value of a tick label, including SI suffixes (`10G`, `500k`), scientific notation and units (`dB`, `°`); `NaN` if it is not a number. `NUM_TICK_RE`/`SI_PREFIX` just above define the accepted syntax.
- **Lines 317-320 `_time_label_seconds`:** Seconds of day of an `HH:MM` or `HH:MM:SS` label.
- **Lines 323-338 `_state_axis_labels`:** Finds the categorical Y-axis labels of state charts (e.g. `Idle/Search/Check/Lock`): texts sharing the same X column, at different heights, left of the plot area. Isolated texts (legend entries, axis titles) are ignored.
- **Lines 341-383 `svg_axes_from_ticks`:** Collects every text of an SVG with its absolute position and classifies it as `num`, `time` or `state`; returns the ticks `DataFrame` and the pixel box of the axes (X from the time ticks, Y from the numeric or state ticks).

**Finding the charts and the curve**
- **Lines 386-408 `_load_object_svg`:** Loads the SVG of an `<object data=...>`: base64 data URI, remote URL (30 s timeout) or local file resolved relative to the HTML report.
- **Lines 411-438 `collect_section_svgs`:** The charts of a section: SVGs found after the header and before the next `h2`/`h3`. Inline SVGs without any text are icons and are skipped; `load_objects=False` only checks for presence (used to decide whether a section has charts).
- **Lines 441-522 `extract_curve_for_header`:** Single-curve extraction: takes the SVG with most `gnuplot_plot_*` groups and, among all subpaths/polylines, keeps the one with most points inside the axes box (this discards the legend sample, which lies outside it).
- **Lines 525-611 `extract_curves_for_header`:** Multi-curve variant used for the antenna chart: returns up to 10 distinct candidate curves of all SVGs with their ticks, series label and colour, best-scoring first.

**Pixel → value mapping**
- **Lines 614-636 `_time_tick_fit`:** Linear fit of X pixel → seconds on the `HH:MM` tick labels, unwrapping midnight crossings and expressed relative to the session start time.
- **Lines 639-668 `map_x_to_time`:** Adds `t_sec_rel` (seconds from start time), `time_HH:MM:SS` and `time_iso_utc`. Uses the tick fit when the chart has at least two time ticks, so all sections share the same time base; otherwise stretches the curve over Start→Stop.
- **Lines 671-708 `map_y_from_ticks`:** Y pixel → value: least-squares line on the numeric ticks (at least two distinct heights). For categorical state charts each point snaps to the nearest label; the value is the level index from the bottom (0, 1, 2, ...) with an extra `<section>_state` column holding the label (plain locked/unlocked axes map to 1/0).
- **Lines 711-716 `safe_sheet_name`:** Excel sheet name: forbidden characters replaced, at most 31 characters.

**Series helpers and output name**
- **Lines 719-741 `_svg_series_color`:** Stroke/fill colour of a curve (attribute or inline style).

   135	def _trim_final_high_elevation(
   136	    frame: pd.DataFrame, threshold: float = 5.0
   137	) -> pd.DataFrame:
   138	    """Drop trailing samples after the pass (antenna moving back to its park position).
   139	
   140	    The frame is cut after the last sample at or below *threshold*. This is
   141	    done only when that sample lies in the second half of the pass: a pass
   142	    that ends above the threshold is kept whole instead of being truncated
   143	    to its first few samples.
   144	    """
   145	    if frame.empty:
   146	        return frame
   147	    elevation = pd.to_numeric(frame[EL_COL], errors="coerce").reset_index(drop=True)
   148	    low = elevation.index[elevation <= threshold]
   149	    if len(low) == 0:
   150	        return frame.iloc[0:0].copy()
   151	    last_low = int(low[-1])
   152	    if last_low < len(elevation) // 2:
   153	        logger.warning(
   154	            "Orbit %s ends above %s deg elevation; trailing samples not trimmed.",
   155	            frame["orbit"].iloc[0], threshold,
   156	        )
   157	        return frame
   158	    return frame.iloc[: last_low + 1].copy()

   215	def _max_center_elevation(series: pd.Series, center_fraction: float = 0.5) -> float:
   216	    if isinstance(series, pd.DataFrame):
   217	        series = pd.Series(series.to_numpy().ravel())
   218	    values = pd.to_numeric(series, errors="coerce").dropna().reset_index(drop=True)
   219	    if values.empty:
   220	        return float("nan")
   221	    if not (0 < center_fraction <= 1):
   222	        center_fraction = 0.5
   223	    window = max(1, int(round(len(values) * center_fraction)))
   224	    start = max(0, (len(values) - window) // 2)
   225	    end = start + window
   226	    return float(values.iloc[start:end].max())

   229	def _signed_elevation(series: pd.Series) -> pd.Series:
   230	    numeric = pd.to_numeric(series, errors="coerce")
   231	    if numeric.dropna().empty:
   232	        return series.copy()
   233	    max_index = numeric.idxmax()
   234	    signed = numeric.copy()
   235	    before_mask = signed.index < max_index
   236	    signed[before_mask] = -signed[before_mask].abs()
   237	    signed[~before_mask] = signed[~before_mask].abs()
   238	    return signed

   414	def _group_by_repeat_cycle(
   415	    items: List[Tuple[pd.DataFrame, pd.Timestamp]],
   416	    period: pd.Timedelta,
   417	    tolerance: pd.Timedelta,
   418	) -> List[List[Tuple[pd.DataFrame, pd.Timestamp]]]:
   419	    """Group passes that fall in the same slot of the ground-track repeat cycle.
   420	
   421	    Each pass gets a phase = (start - first start) mod *period*. Passes whose
   422	    phases are within *tolerance* of each other (also across the cycle
   423	    boundary) form one group, so passes a few minutes apart are no longer
   424	    split just because they straddle an hour boundary.
   425	    """
   426	    if not items:
   427	        return []
   428	    origin = min(start for _, start in items)
   429	    phased = sorted(
   430	        (((start - origin) % period, frame, start) for frame, start in items),
   431	        key=lambda entry: (entry[0], entry[2]),
   432	    )
   433	    groups: List[List[Tuple[pd.Timedelta, pd.DataFrame, pd.Timestamp]]] = [[phased[0]]]
   434	    for entry in phased[1:]:
   435	        if entry[0] - groups[-1][-1][0] <= tolerance:
   436	            groups[-1].append(entry)
   437	        else:
   438	            groups.append([entry])
   439	    if len(groups) > 1 and groups[0][0][0] + period - groups[-1][-1][0] <= tolerance:
   440	        groups[0] = groups.pop() + groups[0]
   441	    return [
   442	        sorted(((frame, start) for _, frame, start in group), key=lambda item: item[1])
   443	        for group in groups
   444	    ]

   447	def _frames_from_existing_output(output_path: Path) -> List[Tuple[pd.DataFrame, pd.Timestamp]]:
   448	    """Rebuild per-orbit frames from the "Group N" sheets of a previous output.
   449	
   450	    Only the data block is read (it ends at the first empty row, before the
   451	    correlation table); helper and chart columns are ignored.
   452	    """
   453	    items: List[Tuple[pd.DataFrame, pd.Timestamp]] = []
   454	    sheets = pd.read_excel(output_path, sheet_name=None, header=1)
   455	    for sheet_name, df in sheets.items():
   456	        if not re.fullmatch(r"Group \d+", sheet_name) or df.empty:
   457	            continue
   458	        empty_rows = df.index[df.isna().all(axis=1)]
   459	        if len(empty_rows):
   460	            df = df.loc[: empty_rows[0] - 1]
   461	        orbits = sorted({
   462	            int(m.group(1))
   463	            for col in df.columns
   464	            if (m := re.fullmatch(r"Orbit (\d+) time_iso_utc", str(col)))
   465	        })
   466	        for orbit in orbits:
   467	            cols = {key: f"Orbit {orbit} {key}" for key in (TIME_COL, AZ_COL, EL_COL, SNR_COL)}
   468	            if not all(c in df.columns for c in cols.values()):
   469	                continue
   470	            frame = df[list(cols.values())].rename(columns={v: k for k, v in cols.items()})
   471	            frame[TIME_COL] = pd.to_datetime(frame[TIME_COL], errors="coerce", utc=True)
   472	            for key in (AZ_COL, EL_COL, SNR_COL):
   473	                frame[key] = pd.to_numeric(frame[key], errors="coerce")
   474	            frame = frame.dropna().reset_index(drop=True)
   475	            if frame.empty:
   476	                continue
   477	            frame["orbit"] = orbit
   478	            items.append((frame[[TIME_COL, SNR_COL, AZ_COL, EL_COL, "orbit"]], frame[TIME_COL].min()))
   479	    return items

### Explanation
Multi-orbit SNR analysis of the Excel files produced by `Extract_all_charts.py`
(formerly the separate *Report_Analysis* repository, whose history is kept).

- **Lines 1-8:** Module docstring.
- **Lines 9-21:** Imports; `openpyxl` is used directly for the charts and for reading sheet headers.
- **Lines 28-40 `_open_excel`:** Opens a workbook, retrying with the `openpyxl` engine when pandas mis-detects it.
- **`SNR_COL`/`AZ_COL`/`EL_COL`, `SERIES_PATTERNS`:** Canonical column names and the suffix patterns used to find them: old reports have `6_1_azimuth`/`6_2_elevation` sheets, newer ones a single antenna sheet with `<section>_azimuth`/`<section>_elevation`; section numbers change between report versions.
- **Lines 59-69 `_sheet_headers`:** First-row headers of every sheet, read once (read-only mode).
- **Lines 72-93 `_find_series`:** Sheet and column holding SNR, azimuth or elevation; raises `ValueError` when missing, which marks a workbook as "not a MEOS export".
- **Lines 96-108 `_load_series`:** Loads one series with its UTC time, rounded to the second, sorted and de-duplicated.
- **Lines 111-132 `_process_file`:** One orbit: pairs each SNR sample with the nearest azimuth/elevation sample (`merge_asof`, 2 s tolerance), adds the orbit number and trims the end of the pass.
- **Lines 135-158 `_trim_final_high_elevation`:** Cuts what follows the last sample at or below 5° (the antenna moving back to its park position) when that sample is in the second half of the pass; a pass ending above 5° is kept whole, with a warning.
- **Lines 161-196 `_extract_start_time`:** `start_time_utc` from the `__meta__` sheet.
- **Lines 199-206 `_extract_orbit`:** Orbit number from the file name (`..._orbit_1234.xlsx`).
- **Lines 209-212 `_bin_series`:** Rounds values to a tolerance grid.
- **Lines 215-226 `_max_center_elevation`:** Highest elevation in the central half of a pass (X-axis limit of the charts, ignoring edge artefacts).
- **Lines 229-238 `_signed_elevation`:** Elevation made negative before the peak (ascending) and positive after it (descending).
- **Lines 241-272 `_build_correlation_table`:** SNR of every orbit of a group at the azimuth/elevation bins they all share.
- **Lines 275-411 `_add_group_chart_sheet`:** "Group N Chart" sheet: two scatter charts, SNR vs elevation for the ascending and descending part, one series per orbit (helper columns written next to the data).
- **Lines 414-444 `_group_by_repeat_cycle`:** Groups passes by their phase in the ground-track repeat cycle (default 9 days): passes whose start times fall within a tolerance (default 30 min) of each other, also across the cycle boundary, form one group.
- **Lines 447-479 `_frames_from_existing_output`:** Rebuilds the orbits already in an existing output from its "Group N" sheets (data block only, up to the first empty row), so new runs add orbits instead of duplicating columns.
- **Lines 482-682 `run_analysis`:** The analysis as a function, used by the CLI and the GUI: reads every MEOS workbook of a folder (others are skipped), merges the orbits of an existing output unless `replace=True`, groups them and writes one "Group N" and one "Group N Chart" sheet per group. Returns a summary; raises `ValueError` when nothing usable is found.
- **Lines 685-747 `main`:** Command-line wrapper (`argparse`), configures logging and turns `ValueError` into an error exit.

Key data structures: per-orbit `DataFrame` (`time_iso_utc`, SNR, azimuth, elevation, `orbit`), dict orbit → (frame, start time), lists of groups.

Relevant Python concepts: `pd.merge_asof` for nearest-time joins, `Timedelta` arithmetic (`%` for the cycle phase), openpyxl `ScatterChart`/`Reference`/`Series`, module-level `logging` so messages reach whichever front end configured it.

   128	
   129	    if progress:
   130	        progress(len(summary["saved"]) + len(summary["errors"]), len(reports), None)
   131	
   132	    if selected_stats and summary["saved"]:
   133	        stats_path = output_dir / "lock_state_stats.xlsx"
   134	        if stats_rows:
   135	            pd.DataFrame(stats_rows, columns=["Orbit Number", "Unlocks"]).to_excel(stats_path, index=False)
   136	        else:
   137	            pd.DataFrame([{"Orbit Number": "N/A", "Unlocks": 0}]).to_excel(stats_path, index=False)
   138	        logging.info("Salvate statistiche: %s", stats_path)
   139	        summary["extra"].append(stats_path)
   140	
   141	    if selected_plots and summary["saved"]:
   142	        if make_combined_plots:
   143	            plot_rows.extend(
   144	                generate_combined_polar_plot_artifacts(output_dir, plot_series_rows, selected_plots)
   145	            )
   146	        plot_index = output_dir / "polar_plots_index.xlsx"
   147	        if plot_rows:
   148	            pd.DataFrame(plot_rows).to_excel(plot_index, index=False)
   149	            logging.info("Salvato indice plot polari: %s (%d plot)", plot_index, len(plot_rows))
   150	            summary["extra"].append(plot_index)
   151	        else:
   152	            logging.warning(
   153	                "Plot polari richiesti ma nessuno generato: controllare i warning nel log."
   154	            )
   155	
   156	    if multi_orbit and summary["saved"] and not summary["stopped"]:
   157	        logging.info("Analisi multi-orbita sugli Excel in %s…", output_dir)
   158	        try:
   159	            result = run_analysis(output_dir, output_dir / DEFAULT_OUTPUT_NAME)
   160	            logging.info(
   161	                "Salvata analisi multi-orbita: %s (%d orbite, %d gruppi)",
   162	                result["output"], len(result["orbits"]), result["groups"],
   163	            )
   164	            summary["extra"].append(result["output"])
   165	        except Exception:
   166	            logging.exception("Analisi multi-orbita non riuscita")
   167	            summary["errors"].append(Path(DEFAULT_OUTPUT_NAME))
   168	
   169	    return summary

   217	def _checkbox_image(root, checked, enabled=True, size=16):
   218	    """Draw a rounded checkbox indicator as a PhotoImage (no external assets)."""
   219	    img = PhotoImage(master=root, width=size, height=size)
   220	    fill = (ACCENT if enabled else "#93C5FD") if checked else ("#FFFFFF" if enabled else "#F1F5F9")
   221	    border = fill if checked else ("#94A3B8" if enabled else "#CBD5E1")
   222	    img.put(fill, to=(1, 1, size - 1, size - 1))
   223	    img.put(border, to=(2, 0, size - 2, 1))
   224	    img.put(border, to=(2, size - 1, size - 2, size))
   225	    img.put(border, to=(0, 2, 1, size - 2))
   226	    img.put(border, to=(size - 1, 2, size, size - 2))
   227	    for x, y in ((1, 1), (size - 2, 1), (1, size - 2), (size - 2, size - 2)):
   228	        img.put(border, to=(x, y, x + 1, y + 1))
   229	    if checked:
   230	        # check mark: short stroke down-right, long stroke up-right (2 px thick)
   231	        pts = [(4, 8), (5, 9), (6, 10), (7, 11)] + [(8, 10), (9, 9), (10, 8), (11, 7), (12, 6), (13, 5)]
   232	        for x, y in pts:
   233	            img.put("#FFFFFF", to=(x - 1, y - 1, x + 1, y + 1))
   234	    return img

   337	class QueueLogHandler(logging.Handler):
   338	    """Forward log records to the Tk thread through a queue."""
   339	
   340	    def __init__(self, q):
   341	        super().__init__()
   342	        self.q = q
   343	
   344	    def emit(self, record):
   345	        try:
   346	            self.q.put(("log", record.levelno, self.format(record)))
   347	        except Exception:  # pragma: no cover
   348	            self.handleError(record)

    13	def load_license(path: Path) -> dict[str, str] | None:
    14	    """Return the license information from *path* or ``None`` if not found."""

    16	        return json.loads(path.read_text(encoding="utf-8"))

    20	def validate_license(path: Path) -> bool:
    21	    """Validate the license file using HMAC/SHA256.
    22	
    23	    The license file must contain ``client``, ``expires`` and ``signature`` fields.
    24	    The signature is expected to be the hex digest of
    25	    ``HMAC(SECRET_KEY, f"{client}|{expires}")``.
    26	
    27	    When running from a PyInstaller ``--onefile`` bundle, ``license.key`` may be
    28	    packaged inside the executable. In that case ``sys._MEIPASS`` points to the
    29	    temporary extraction directory. This function will look for the license file
    30	    there if it is not found at the provided path.
    31	    """
    32	    lic_path = path
    33	    if not lic_path.exists():
    34	        meipass = getattr(sys, "_MEIPASS", None)
    35	        if meipass:
    36	            alt = Path(meipass) / path.name
    37	            if alt.exists():
    38	                lic_path = alt
    39	
    40	    lic = load_license(lic_path)
    41	    if not lic:
    42	        return False
    43	
    44	    client = lic.get("client")
    45	    expires = lic.get("expires")
    46	    signature = lic.get("signature")
    47	    if not (client and expires and signature):
    48	        return False
    49	
    50	    payload = f"{client}|{expires}".encode("utf-8")
    51	    expected = hmac.new(SECRET_KEY, payload, hashlib.sha256).hexdigest()
    52	    if not hmac.compare_digest(signature, expected):
    53	        return False
    54	
    55	    try:
    56	        exp_date = datetime.strptime(expires, "%Y-%m-%d").date()
    57	    except ValueError:
    58	        return False
    59	
    60	    return date.today() <= exp_date

### Explanation
PyInstaller recipe (`pyinstaller meos_extract.spec`), a Python file executed by PyInstaller.

- Two `Analysis` blocks: `Extract_all_charts.py` (console executable `extract_cli`) and `gui_app.py` (windowed executable `extract_gui`). `report_analysis.py` is bundled automatically because the GUI imports it.
- `hiddenimports` lists libraries PyInstaller may not detect on its own (`bs4`, `pandas`, `numpy`, `openpyxl`).
- `datas` copies `license_checker.py` next to the executables as a plain file (it is not imported by the current code).
- `COLLECT` puts both executables and their shared libraries in one `MEOS-Extract` folder.
